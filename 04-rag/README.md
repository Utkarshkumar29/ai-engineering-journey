# Retrieval-Augmented Generation (RAG)

RAG retrieves relevant information from a knowledge source and supplies it to a model as context for an answer.

Learning checklist:
- [ ] Document ingestion and parsing
- [ ] Chunking strategies
- [ ] Embeddings and vector similarity
- [ ] Retrieval and reranking basics
- [ ] Grounded answers with source references
- [ ] Retrieval evaluation
- [ ] Permissions, freshness, and deletion

First experiment: use a small set of non-sensitive documents and prepare 10 questions with expected source passages.
