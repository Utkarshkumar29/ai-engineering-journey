# Local Models and Ollama

Explore local inference when privacy, offline use, experimentation, or predictable usage economics justify it.

- [ ] Install Ollama using the official instructions.
- [ ] Check available RAM, VRAM, and disk space before selecting a model.
- [ ] Run a model and test a small repeatable prompt set.
- [ ] Compare quality, latency, and resource use with a hosted API.
- [ ] Document limitations and hardware requirements.

Local inference is optional. Do not purchase hardware solely to complete this roadmap.
