# AI Agents

Study agent systems as bounded loops that use models to choose among explicitly provided tools.

Checklist:
- [ ] Understand workflow vs agent trade-offs
- [ ] Define a small tool allow-list
- [ ] Validate tool arguments and results
- [ ] Set step, time, and cost limits
- [ ] Add human approval for consequential actions
- [ ] Log tool calls and outcomes
- [ ] Test ambiguous requests and failure cases

An agent should not receive broad credentials or unrestricted access just because it can call tools.
