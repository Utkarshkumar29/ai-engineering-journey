# AI Applications

Patterns for adding language-model capabilities to software.

- [ ] Server-side model API integration
- [ ] Structured output and schema validation
- [ ] Tool/function calling
- [ ] Human approval for sensitive actions
- [ ] Timeouts, retries, rate limits, and cost controls
- [ ] Observability and evaluation

Prefer deterministic code for deterministic business rules. Do not let an LLM bypass authorization or decide whether a user is allowed to access data.
