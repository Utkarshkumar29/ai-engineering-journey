# Projects

Each project should have its own folder and README.

A project is considered portfolio-ready when it includes:
1. Problem statement and target user.
2. Requirements and non-goals.
3. Architecture and data-flow diagram.
4. Setup and configuration instructions.
5. Demo or screenshots using synthetic data.
6. Test cases and evaluation results.
7. Security/privacy notes and known limitations.
