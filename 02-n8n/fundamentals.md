# n8n Fundamentals

## What is n8n?

n8n is a workflow automation platform. A workflow connects nodes so that an event or trigger can start a sequence of actions, transformations, and decisions.

## Core terms

- **Workflow:** The complete automation.
- **Node:** A step that performs a trigger, action, transformation, or decision.
- **Trigger:** Starts a workflow, for example a webhook or schedule.
- **Execution:** A run of a workflow.
- **Credentials:** Stored authentication details used by nodes.
- **Expression:** A way to reference data from earlier nodes.
- **Webhook:** An HTTP endpoint that can start a workflow when it receives a request.
